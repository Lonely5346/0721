程序编写参考于B站及头歌大作业学生成绩管理系统,Python爬虫相关内容
程序优化阶段运用了AI进行了bug查找
注意：
    1.不要短时间内多次重复运行程序，可能导致ip封禁，无法获取爬虫数据导致程序运行失败；
    2.运行程序所需Python库：requests，json，matplotlib，请确保Python运行环境配置好以上函数库；
    3.代码已上传GitHub，可从https://github.com/Lonely5346/0721 下载;
    4.使用Anaconda需要手动配置Spyder的环境，需要在Anaconda Navigator的Environments 中搜索matplotlib等库进行配置，若依旧有问题，请更新Spyder版本;
   5.VS，Pycharm运行请选择交互式窗口运行，直接终端运行无法输出图表;
   6.确保设备“C:/Windows/Fonts/simhei.ttf”路径存在;
    7.若提示“Output is truncated. View as a scrollable element or open in a text editor. Adjust cell output settings...”，请点击“scrollable element”的蓝色字样，原因是窗口展示文本过长，系统自动隐藏省略中间部分内容;
